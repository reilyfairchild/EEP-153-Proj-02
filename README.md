# Project 2: Food Price Optimization and Visualization

## Repository Overview

This repository contains all the code, data, and visualizations for our project on food price optimization, where we aim to balance dietary requirements with cost efficiency. Below is a breakdown of the repository structure and the purpose of each file.

## File Structure

- **Project\_2\_Final\_Code.ipynb**: This notebook contains all the code necessary to achieve the project deliverables, including data processing, analysis, and final output generation.

- **Visualization Notebooks:**

  - `Visualization1.ipynb`
  - `Visualization2.ipynb`
  - `Visualization3.ipynb`
  - `Visualization4.ipynb`
  - `Visualization5.ipynb`
  - `Visualization6.ipynb`: 

- **Data Files:**

  - `diet_max.csv`: Contains the minimum meal prices.
  - `food_and_prices1.csv`: Raw data for available foods and their corresponding prices.
  - `Dietary_Requirements.csv`: Nutritional requirements categorized by age and sex.

- **Data Processing:**

  - `Generating_food_table.ipynb`: This notebook combines and processes the food and nutritional data into a comprehensive DataFrame for analysis and visualization.

## Usage

1. Clone the repository:

```bash
git clone <repository_url>
```

2. Install the required packages (if applicable):

```bash
pip install -r requirements.txt --upgrade
pip install wbdata
```

3. Run the notebooks in sequence for data preparation, optimization, and visualization.

## Project Goal

Our project aims to analyze the comparative costs of a vegan diet versus an omnivorous diet within the American population, with a specific focus on their environmental impact.
